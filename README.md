# 🏠 House Price Prediction using Linear Regression

This project predicts house prices based on various factors such as area, number of bedrooms, furnishing status, and more.

## 📊 Features
- Data Cleaning & Encoding
- Feature Scaling with StandardScaler
- Correlation Analysis with Heatmap
- Linear Regression Model Training
- Predicts new house prices

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-Learn
- Matplotlib, Seaborn

## 📈 Result
Model R² Accuracy: ~80-90%
